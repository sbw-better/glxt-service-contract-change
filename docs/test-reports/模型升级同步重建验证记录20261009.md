## 数据库隔离方式

真实测试环境为本地 Oracle **23**，不是 Oracle 11g。测试以随机短前缀创建独立历史样本表、单行控制表、序列、约束和索引，加载对应生产Mapper SQL；结束时只清理本次创建的测试对象。没有修改已有业务表、执行已有库迁移或清库。

`OracleSampleLibraryIntegrationTest`验证重建事务和写入占用；`OracleVectorClobIntegrationTest`验证生产CLOB映射的新增、读取、更新及回滚。向量均由确定性测试替身提供。

## 未验证及运行边界

- 尚未在Oracle 11g运行；SQL按现有Oracle兼容写法实现，但不能以23环境结果替代11g验收。

- 同步请求耗时取决于模型批次、延迟及重试，尚未进行真实几百条网关压力测试；客户端和代理超时需结合实测设置。

- 已有库复合约束调整及控制信息初始化需要单独确认，本次未执行。`01_schema.sql`只用于新库初始化。
