## 发现及修复

1. CommonUtils误导入javax.xml.soap.Text，Java17编译报包不存在；且该类型不是Word文本节点。改用org.docx4j.wml.Text。
2. 两份docx Mapper XML的parameterType仍指向原domain包。实际启动复现ClassNotFoundException：com.citics.glxt.contractchange.domain.ContractAnalysisDetail。namespace和parameterType统一改为迁移后的docx包。
3. 启动类仅扫描原mapper包，补充docx.mapper，使该模块包括未标注@Mapper的接口都能注册。
4. 三份既有测试缺少迁移后的DocxAnalysisDTO导入，补齐以恢复测试编译。
